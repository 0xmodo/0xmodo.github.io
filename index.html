01 / ABOUT

Curiosity, from the
browser down.

My interests sit where frontend engineering meets software architecture. I enjoy the detail of an interface, but I’m just as interested in what happens behind it: where state lives, how components communicate, and how a design holds up as it grows.

Outside work, personal projects are my way of learning through implementation. Recently that has meant drawing tools and browser graphics. Next, I want to go deeper into stateful systems, realtime communication, and database internals.

01PLANNED

A small Durable
Objects-inspired system

Build a learning implementation inspired by Cloudflare Durable Objects. Start with the idea of an object that owns its state, then explore request coordination, persistence, and recovery.

How much simpler can a system become when state has a clear owner?

02PLANNED

A Realtime-inspired
change stream

Build a small implementation inspired by Supabase Realtime. Explore how database changes reach connected clients, with subscriptions, reconnects, and delivery behavior as the learning goals.

What does it take to keep a browser in step with changing data?
